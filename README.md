# NLP_Group_05
# Fake News Detection - Naive Bayes Model

## Overview

This branch contains the Machine Learning implementation of the Fake News Detection project using the Multinomial Naive Bayes algorithm.

## Model

- Machine Learning Model: Multinomial Naive Bayes
- Feature Engineering: TF-IDF Vectorization

## NLP Pipeline

- Data Collection
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- TF-IDF Feature Engineering
- Naive Bayes Model Training
- Model Evaluation

## Files Included

- 1_data_collection.py
- 2_preprocessing.py
- 3_eda.py
- 4_feature_engineering.py
- 5_model_naive_bayes.py
- 7_evaluation.py

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC

## Output

The trained Naive Bayes model is evaluated and compared with the CNN model in the final project.
